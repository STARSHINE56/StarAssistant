# 星辰助手

一款面向 Android 的多网盘文件管理与分享链接解析工具，支持账号管理、文件浏览、链接解析、转存与下载任务管理。

> 本项目仅用于学习、研究和管理本人有权访问的文件。请遵守当地法律法规、网盘服务条款与内容版权要求，请勿用于侵犯他人权益。

## 功能

- 支持百度网盘、移动云盘、夸克网盘、123 云盘、UC 网盘、迅雷云盘、115 网盘、光鸭云盘、蓝奏云及蓝奏云优享版
- 分享链接识别、文件列表浏览与保存
- 下载任务、下载历史、进度、暂停、继续与重新下载管理
- 内置下载器和 Gopeed 引擎切换，共用最大同时下载数；磁力／BT 下载
- GitHub 仓库浏览和下载、主页收藏快捷方式、云盘新建文件夹
- 可配置公告来源（默认关闭）、诊断模式及脱敏日志导出
- 账号信息本地保存及加密备份
- Material 3 界面、深色模式与主题外观设置
- 应用内更新检查和崩溃日志导出

## 下载与安装

1. 打开仓库右侧的 **Releases**。
2. 下载最新版本的 `星辰助手-v*.apk`。
3. 在 Android 设备上允许浏览器或文件管理器安装未知来源应用，然后安装 APK。

正式版本使用独立 Release 密钥签名。升级时必须使用相同签名；请只从本仓库 Releases 下载。

## 本地构建

环境要求：JDK 17、Android SDK 36。

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

APK 输出位置：`app/build/outputs/apk/debug/app-debug.apk`。

## 1.1.0 上游同步

本次移植固定来自 YunX `v1.2.9`（`ccc862246c95134607af35ebc88537cbb973f553`），保留星辰助手品牌、包名、更新源、历史任务、账号及设置。数据库通过 16 → 17 增量迁移升级，认证备份兼容旧版。

Gopeed Java 桥接类随 APK 提供；原生内核在「设置 → 下载引擎」中获取或导入，与上游一致按设备 ABI 选择 `arm64-v8a`、`armeabi-v7a`、`x86_64` 或 `x86` 的 AAR。下载失败、摘要或 ELF 架构校验失败时不会替换已安装内核。Gopeed 需可写文件系统目录；内置下载器继续支持 SAF 目录。BT 沿用上游默认停止做种设置。

公告来源需在设置中配置自己的 HTTPS 公告 API；未配置时不会请求上游作者公告。自动测试及 APK 构建不能替代真实平台账号和 Android 设备上的验证。

## 1.1.4 内核下载修复

本次修复了首次下载 Gopeed 内核时可能出现的 `内核下载失败` 错误。

- 修复：首次下载内核时，私有目录 `gopeed/kernel/` 尚未创建，直接写入 `download_identity` 标记文件会抛出 `ENOENT (No such file or directory)` 异常。现在会在写入标记前先确保目录存在。
- 影响：全新安装、或清除应用数据后第一次进入「设置 → 下载引擎」获取内核时，不再卡在目录不存在的报错上。
- 其他：无界面与行为变更，仅修复上述边界情况。

## 1.1.5 上游功能同步（动图 / 深链接 / 下载重连）

本次同步上游 YunX `v1.3.0` 之后的三个功能提交（`#202`、`#204`、`#206`），保留星辰助手品牌、包名、更新源与既有数据。数据库通过 22 → 23 增量迁移升级，历史下载任务与账号不受影响。

### 动图（Live Photo）解析与「动态照片」合成

- 新增：抖音、微博的动图作品现在可以下载成一张**会动的照片**。产物是单个 `.jpg`，内部为 Motion Photo 格式（静图 + 尾部追加 MP4 + XMP），小米 / OPPO / vivo 等安卓相册会按「动态照片」展示。换成 iPhone 上只是普通图片——苹果的 Live Photo 是另一种「静图 + 配对 MOV」两文件格式。
- 新增：动图资源不是 mp4 时（微博给的是 `.mov`）会先换封装再合成，只搬样本、不重新编码，秒级完成。
- 变更：带动图的任务强制走内置下载器——Gopeed 引擎没有合成能力。
- 解析预览：动图作品点预览时直接播「会动的那一半」，比只显示一张静图更贴近预期。

### 链接一键唤起

- 新增：「设置 → 链接唤起」里可以按平台逐个开关深链接接管，覆盖夸克、UC、迅雷、百度、139、123、115、光鸭、蓝奏云 / 优享版、磁力链接、分享菜单，以及长按选中文字后的「用星辰助手解析」。
- 说明：这些入口一律不开 `autoVerify`——`pan.quark.cn` 这类域名不是我们的，放不了 `assetlinks.json`，校验失败反而会被系统排除。所以首次点链接会弹「打开方式」，选过之后可设为默认。

### 迅雷网页账号「验证码无效」修复

- 修复：网页端登录时验证码校验经常失败的问题（签名链路按网页当前算法重建）。
- 新增：认证备份现在包含视频解析平台的账号，换机时哔哩哔哩 / 抖音等平台的登录态也能一起迁移。

### 下载进度与卡死判定

- 修复：界面显示「已下载 > 总大小」、进度永远卡在 100% 但任务下不完的问题。旧版本可能往库里写下虚高进度，恢复时又只在大小时才回写，导致这个值再也压不回来。现在只要与磁盘真实进度不一致就双向校正。
- 修复：合轨任务（B 站 DASH 高清）的进度条与速度不再恒为 0。两段音视频流的 `Content-Length` 会累加作为任务总大小，下载过程中实时上报速度与剩余时间。
- 修复：合轨阶段现在会显示「合并中 n%」。此前两轨下完进度就到 100%，而逐样本重封装还要几十秒，看着像卡死。
- 改善：「自动重连」与调试页的「强制重连」现在会**真的掐断**在飞连接。以前只置一个标志位，当连接被 CDN 挂住（`read` 阻塞）时根本轮不到检查标志，表现就是「标了卡死、但那条连接一直不换」。
- 改善：判断连接是否该换，从「瞬时速度低」改为同时参考「多久一个字节都没收到」。瞬时速度低只说明慢，长时间零字节才是连接被挂死的直接证据；日志与调试页也会写明「无数据 Ns」。
- 改善：分轨流式下载支持 `Range` 断点续传与断流重试（最多 3 次），弱网下不再因为一次断流就整段重下。

### 大文件分片下载「大量丢包」（v1.1.8）

- 修复：服务端声明 N 字节、CDN 中途掐流只吐出 M 字节（M < N）时，整片被判失败、已落盘的 M 字节白扔。现在保留进度并换连接从断点续传，连续 8 次都写不满才判失败。
- 修复：慢连接抢占（主动掐掉龟速连接换快的）以前占用重试额度，弱网下 7 次额度被抢占烧光、分片照样判死。现在抢占与短写续传都不消耗额度，也不退避等待。
- 修复：分片文件比应有长度还长时直接判失败，而补传只挑「不足」的片，超长片永远没人处理，于是每次合并都卡在「文件大小校验失败」，只能删任务重下。现在就地截断重下；合并前的尺寸校验发现超长片时按应有长度删掉重下。
- 修复：拥塞时连接数减半的下限是 1，弱网 / 风控期会永久停在单连接龟速，且每次失败把冻结期重置成 30 秒再也爬不回来。现在下限 2 路、冻结 15 秒。
- 修复：`CookieHeader.merge` 用了 API 24 才有的 `HashMap.putIfAbsent`，而本项目 minSdk = 23，Android 7.0 / 7.1 上一调用就 `NoSuchMethodError` 闪退。改为等价的 `containsKey` 判断。

### 界面精简（v1.1.8）

- 删掉「设置 → 同步功能 → 公告来源」自定义入口，公告固定读官方 COS 直链。手填地址填错只会让公告整块静默失效、界面还不报错。
- 删掉「支持开发」整个赞助功能：设置页入口、整张捐赠页（含赞助码轮播卡片、二维码保存到相册）、覆盖层与图片资源全部移除。项目不再接受捐赠。

### 兼容性说明

星辰助手的最低支持版本仍是 Android 6.0（API 23），比上游的 24 更低。为此这几处上游写法做了等价替换：`MediaFormat.getInteger(String, Int)`（API 29）改为单参调用 + 默认值兜底；`SimpleDateFormat` 的 `X` 模式（API 24）改为 `Z` + 时区归一化。功能行为不受影响。

上游的反篡改校验（`LaunchGate` / `ArchiveProbe` / `TextCipher`）**未**同步：它会读取 `/proc/<pid>/maps` 检测注入类与外部 `.so` 并直接终止进程，与星辰助手的改造环境不兼容。

自动测试（单元测试 + Lint + Debug 构建）不能替代真实网盘账号与真机验证。动图合成、深链接唤起、迅雷网页登录这几项建议在真机上实际走一遍。

## 1.2.0 上游同步（YunX v1.3.1）

本版把上游 v1.3.0 → v1.3.1 的全部改动整体移植进来，原有功能一个没删。因为星辰助手当初是整份代码另起炉灶（与上游**没有共同提交历史**，`git merge-base` 为空），cherry-pick 用不了，实际做法是以「已移植的 `4bd22e4`」为共同基线做逐文件三方合并：上游改动 103 个文件（+7040 / −1326），其中 39 个自动合并干净、16 个是新增文件直接落地、12 个文件 50 处冲突逐块手工合并。

### 新增功能

- **个人盘上传**：夸克网盘支持上传本地文件（`data/upload/QuarkUploader.kt`），上传前流式算哈希、大文件可续传。
- **缩略图网格**：文件列表可按「列表 / 缩略图」切换（设置 → 通用 →「列表缩略图」），缩略图走 `coil` 异步加载，失败回落文件类型图标。
- **在线预览**：图片 / 视频 / 音频 / 文本 / PDF 直接在应用内预览，视频走 HLS 或 DASH（`preview/` 下新增 8 个文件），DASH 由内置 `DashMuxer` 处理。
- **账号页排序**：网盘页标题栏新增「排序网盘」，可拖动调整账号顺序、隐藏未登录账号；顺序持久化，排序弹窗里连被隐藏的项一起排。
- **139 云盘口令**：与已有的链接分享、迅雷口令并列，粘贴 139 口令直接解析（`C139KoulingParser`）；剪贴板自动识别、粘贴按钮、候选卡片全部同步支持。
- **GitHub Token 直达链接**：Token 弹窗里加「↗ 从 GitHub 获取 Token」，一键跳到预填好 `public_repo` scope 的创建页；没有可用浏览器时复制链接并提示。

### 修复

- 蓝奏云换用新域名 `lanzn.com`，旧域名链接失效；同时把 `*.lanzn.com` 加进 `AndroidManifest.xml` 的深链接 `intent-filter`。
- 蓝奏文件夹分享的下载（此前会解析成空列表）。
- 蓝奏下载文件名归一化（去掉 `?`、`*` 等非法字符，避免写盘失败）。

- 光鸭分享列表翻页丢失。

### 变更：凭据不再加密存储

上游 #208 把账号凭证从 Android Keystore 加密改成明文存储（`PlaintextCredentialCipher`）。原因是 Keystore 自愈逻辑会重建密钥、把读不出来的旧凭证直接作废，导致用户被反复踢下线。星辰助手照此执行，但**保留了旧密文的只读解密路径**（别名 `yunx.account.credentials.v1`、`AES/GCM/NoPadding`、格式 `yunx:v1:<iv>:<ct>`，与旧版字节级一致）：升级后老密文照样能解开，随后以明文回写覆盖，**老用户不需要重新登录**。

### 保留的星辰自有改动

上游同步时逐项保住，没有被覆盖回去：v1.1.8 的四处下载可靠性补丁（短写续传、抢占不占额度、超长片截断、拥塞下限 2 路）、界面精简（去掉公告来源设置与整个赞助功能）、品牌与包名 `com.xingchen.assistant`、深链接（`ShareReceiver` / `LaunchGate` 未同步，见上节）、下载调试日志。
