## 跟上上游 v1.3.1：个人盘上传、在线预览、账号页排序

这一版把上游 YunX v1.3.0 之后落下的 6 个提交全部合进来（含 v1.3.1 的主体），
星辰自己这边的下载可靠性补丁、界面精简、深链接与调试日志一律保留。

### 新增

- **个人盘上传**（夸克）：网盘页可以把本机文件上传到自己的夸克网盘，带上传进度与失败重试。
- **缩略图网格**：网盘 / 分享页的图片文件直接显示缩略图，可在「设置 → 通用 → 列表缩略图」关掉。
- **在线预览**：网盘与分享里的图片、视频、音频点开即预览，视频支持 HLS 与 DASH 分轨（有独立音轨的也能出声）。
  预览走系统播放器内核，拖动进度、倍速、横屏都能用。
- **账号页排序**：网盘账号页顶栏多了「排序」按钮，可以拖动调整网盘顺序，并把没登录的网盘折叠起来。
- **139 网盘口令**：`复制整段口令文字` 粘进解析框就能识别，剪贴板自动检测也认。
- **GitHub Token 获取入口**：Token 弹窗里加了「↗ 从 GitHub 获取 Token」，直接跳到预设好 `public_repo`
  权限的创建页，不用在手机上手动翻 Settings → Developer settings 那一串。

### 修复

- **蓝奏云新域名 `lanzn.com`**：2026-10 起蓝奏换了域名族，旧版粘贴 `xxx.lanzn.com/xxx` 会解析不出来，
  点外部链接也拉不起应用。现在解析正则和清单里的 intent-filter 都认这个族。
- **蓝奏文件夹分享**：分享链接是文件夹时列表能正常展开下载，不再只拿到第一个文件。
- **蓝奏下载文件名归一化**：文件名里的非法字符、超长名、重名统一处理，减少「下载完在文件管理器里找不到」。
- **光鸭登录误报**：登录成功后不再闪一下「登录失败」。
- **光鸭分享翻页**：分享页内容多于一页时能翻到底，不再只能看到第一页。

### 变更

- **凭据存储不再加密**：账号 Cookie / Token 从 Android Keystore AES-GCM 改成明文存本地
  （`PlaintextCredentialCipher`）。旧版留下的 `yunx:v1:` 密文仍能只读解开，首次读取后自动明文回写，
  **老用户不需要重新登录**。这么改是为了根除「Keystore 密钥失效 → 自愈重建 → 把所有好凭证一起作废」那条链路。
- 应用启动时仍会恢复你配置的 HTTP 代理；内存吃紧时主动释放空闲连接（不影响进行中的分片下载）。

### 保留（星辰自己的改动，没有跟着上游回退）

- 大文件分片下载的四处修复（短写续传、抢占不烧额度、超长分片自愈、连接数下限 2 路）。
- 界面精简：不设「公告来源」自定义入口（固定官方 COS）、没有「支持开发」赞助页。
- 品牌与包名（`com.xingchen.assistant`）、深链接唤起、下载调试日志、诊断日志。

### 测试

- 单元测试全绿（含新增的上传签名、缩略图、文件名归一化、在线预览用例）。
- Android Lint 通过。
- CI 全流程 success：单测 → Lint → assembleDebug。

### 已知限制

- 上传目前只支持夸克个人盘；其它网盘仍是只读。
- 缩略图与预览依赖网盘返回的直链，链接过期后会退回文件图标。
- 明文存储意味着：能 root 并读到应用私有目录的人可以直接看到账号 Cookie。这是上游 #208 的取舍。
